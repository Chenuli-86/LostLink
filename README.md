# LostLink

LostLink is a proposed C# WPF desktop application for managing and matching lost and found items within a campus environment.

## Purpose

The application is designed to provide a centralised system for recording, searching, and managing lost and found property. LostLink will also provide smart match suggestions by comparing characteristics of lost and found item reports.

## Proposed Functionality

- Staff and administrator access
- Lost item reporting
- Found item reporting
- Search and filtering
- Rule-based match scoring
- Match suggestions
- Claim management
- Dashboard and data visualisation
- Activity logging
- Local database storage

## Matching

LostLink will compare characteristics such as item category, colour, location, date, and description keywords to identify possible matches between lost and found reports.
